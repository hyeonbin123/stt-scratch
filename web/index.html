stt-scratch 스트리밍 자막 (로컬 데모)

서버 설정-
보낸 청크0
마지막 부분 자막 지연(보낸 뒤 → 받음)-

청크당 계산 시간(flush 뒤)-

320 ms마다 16 kHz PCM을 보냅니다. 기울임의 잠정 자막은 320 ms 스트리밍 결과로 글자가 덧붙기만 하고, 끝점(토큰 뒤 묵음)이 걸리면 서버가 그 세그먼트를 같은 모델의 전체 문맥으로 다시 디코딩한 2차 패스 결과가 확정 자막이 됩니다(잠정 자막과 다를 수 있음. 서버를 --final-pass none으로 띄우면 잠정 자막이 그대로 확정). 멈춤을 누르면 남은 음성을 보내고 마지막 세그먼트를 확정한 뒤 연결을 닫습니다.
